# Plan Slice 58 – Kundenbereich auf der eigenen Website einbetten

## Annahmen (bei Freigabe bestätigen)
1. **Ort der Einstellung:** am Mandanten (`Tenant.EmbedAllowedOrigins`, Liste, Spalte `text[]`, Migration `TenantEmbedAllowedOrigins`), nicht am Standort: Der Kundenbereich ist je Spa eine Seite (`?spa=`). Empfohlen: ja.
2. **Format:** nur `https://host` oder `https://host:port`, ohne Pfad (ein einzelner Schrägstrich am Ende wird entfernt), ohne Zugangsdaten, Abfrage und Anker; keine Platzhalter (`*.beispiel.at` wäre eine zu weite Freigabe). Host kleingeschrieben, Duplikate entfallen, höchstens 10 Einträge, je höchstens 200 Zeichen. Fehler am Feld `allowedOrigins`, mit Grund und der fehlerhaften Eingabe; bei einem Fehler wird nichts gespeichert.
3. **Header:** `frame-ancestors` wirkt nur in einer **durchsetzenden** Richtlinie (in `Content-Security-Policy-Report-Only` sperrt der Browser nichts). Deshalb bekommt `/buchen/` zusätzlich zum bestehenden Report-Only-Header einen eigenen Header `Content-Security-Policy: frame-ancestors 'self' <Liste>`. Die Report-Only-Richtlinie bleibt unverändert; beim späteren Durchsetzen (ADR 0080) werden beide zu einer zusammengeführt. „Policy enthält `frame-ancestors 'self'`“ prüfen die Tests am durchsetzenden Header.
4. **Mandant der Seite:** `?spa=<Guid>` der Adresse, sonst der einzige Mandant (wie `OnlineTenant`). Wer in einem Mehr-Mandanten-Betrieb ohne `?spa=` lädt, bekommt `'self'`. Die Einbettungsadresse muss `?spa=` tragen (steht im Hilfetext).
5. **nginx:** nginx kennt die Datenbank nicht. `location /buchen/` holt die Liste per `auth_request` (`ngx_http_auth_request_module`, im offiziellen Image enthalten) von einem anonymen Endpunkt `GET /api/online/embedding-policy?spa=` der API, der den fertigen Wert im Header `X-Frame-Ancestors` liefert; nginx setzt daraus `Content-Security-Policy`. Der Endpunkt hat keine Ratenbegrenzung, damit eine 429 nie die Seite sperrt. Die API im Einzelplatz setzt den Header selbst. Fällt die API aus, antwortet `/buchen/` mit 500 (die Buchung ginge ohnehin nicht).
6. **Rechte:** `GET`/`PUT /api/tenant/embedding` mit `RequirePermission(AccessRight.ManageOrganization)` (wie die Firmendaten, Inhaber).
7. **Oberfläche:** neuer Abschnitt „Kundenbereich einbetten“ unten im Reiter „Firmendaten“ (Textfeld, eine Adresse je Zeile), eigenes Speichern, Hilfe-Abschnitt `{#einbetten}` in `firmendaten.md` mit Fragezeichen. Kein Handbuchablauf mit Bildern (ein Feld; Bild folgt nicht).
8. **ADR:** Nachtrag in `0080-csp-fuer-den-kundenbereich.md` (Regel, nginx-Weg, Umschalten); keine neue Nummer. Die „Offen für den Auftraggeber“-Zeile wird beantwortet.
