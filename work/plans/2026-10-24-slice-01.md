## Review-Fokus
1. Bedingt gerenderte Köpfe (`{!report.amountsHidden && <th …>}`, ManagementView :118, :141) bekommen `scope` ebenfalls.
2. `<th>` mit weiteren Attributen vor `scope` (`<th className="amount" scope="col">`) gilt als gültig; `<thead>` zählt nicht als `<th`.
3. Mehrzeilige Tags und `<th key={c}>` werden bis zum schließenden `>` gelesen (Fall im Test von Aufgabe 1).
4. Rechtsbündig gilt in Hell und Dunkel gleich; `th.amount` setzt nur Ausrichtung und Ziffernbreite.
5. Neue Tabellen künftiger Slices fallen sofort auf, weil die Prüfung ganz `web/src` liest (auch `booking/`).

**Schnittstellen:**
- Erzeugt: `function headersWithoutScope(source: string): string[]` (in der Testdatei) – liefert die Tags `<th…>` ohne `scope=`.

- [ ] **Schritt 1: Fehlschlagenden Test schreiben**

```ts
describe('Tabellenköpfe', () => {
  it('jedes <th> in web/src nennt seine Richtung mit scope', () => {
    const missing = tsxFiles(srcDir).flatMap((file) =>
      headersWithoutScope(readFileSync(file, 'utf-8')).map((tag) => `${relative(srcDir, file)}: ${tag}`))
    expect(missing).toEqual([])
  })
  it('erkennt Köpfe ohne scope und lässt thead und Köpfe mit scope durch', () => {
    expect(headersWithoutScope('<thead><tr><th>A</th><th className="amount" scope="col">B</th><th\n key={c}>C</th></tr></thead>'))
      .toEqual(['<th>', '<th\n key={c}>'])
  })
})
```
Regulärer Ausdruck `/<th(?=[\s>/])[^>]*>/g`, Treffer ohne `scope=` zählen. `tsxFiles` rekursiv über `readdirSync(dir, { withFileTypes: true })`, `srcDir = resolve(import.meta.dirname)`.
