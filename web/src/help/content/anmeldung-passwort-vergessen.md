# Passwort vergessen (Einzelplatz)

Im Einzelplatz-Betrieb setzt normalerweise die Leitung ein vergessenes Passwort neu. Gibt es niemanden mit diesem Recht, z. B. weil die Inhaberin ihr eigenes vergessen hat, geht es mit dem Wiederherstellungsschlüssel.

## Über die Leitung {#leitung}

Die Leitung vergibt unter „Verwaltung“ › „Zugänge“ ein neues Startpasswort, siehe [Neues Startpasswort](hilfe:zugaenge#neues-startpasswort). Beim nächsten Anmelden wählt man ein eigenes Passwort.

## Mit dem Wiederherstellungsschlüssel {#schluessel}

Am Haupt-PC, auf dem die Datenbank liegt:

1. Auf der Anmeldeseite auf **Passwort vergessen?** klicken.
2. „Benutzername“ des Kontos eintragen.
3. Den „Wiederherstellungsschlüssel (24 Zeichen, z. B. K7QM-2XRT-…)“ eintragen, der beim Einrichten der Sicherung notiert wurde.
4. „Neues Passwort (mindestens 8 Zeichen)“ und „Neues Passwort wiederholen“ eintragen.
5. Auf **Passwort setzen und anmelden** klicken.

- **Zurück zur Anmeldung** schließt das Formular.
- Den Schlüssel zeigt die App nur einmal, auf der Seite „Sicherung“; ist er verloren, erzeugt die Leitung dort einen neuen: [Wiederherstellungsschlüssel](hilfe:sicherung#wiederherstellungsschluessel).
- Mit Server gibt es kein Passwort in der App; dort meldet man sich mit einem Code von der Seite „Anmelden“ im Browser an.
- Felder im Einzelnen: [Passwort vergessen](hilfe:einzelplatz#passwort-vergessen).
