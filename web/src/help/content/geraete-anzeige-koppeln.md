# Anzeige im Pausenraum koppeln

Ein Bildschirm im Pausenraum zeigt dem Team den Tag mit Initialen statt Gastnamen. Er bekommt keinen eigenen Zugang mit Person, sondern wird mit einem Code an einen Standort gekoppelt. Koppeln dürfen Inhaber, Manager und Standortleitung.

1. Am Bildschirm im Pausenraum die Anzeige öffnen. Sie zeigt einen Code aus acht Zeichen, z. B. „K7QM-2XRT“.
2. In der Windows-App in der Navigation **Geräte** öffnen und zu „Anzeigen im Pausenraum“ gehen.
3. Den Code bei „Code vom Bildschirm“ abtippen.
4. Bei „Name der Anzeige“ einen Namen eintragen, z. B. „Pausenraum“.
5. Den „Standort“ wählen, dessen Tag die Anzeige zeigen soll.
6. Auf **Anzeige koppeln** klicken. Wenige Sekunden später zeigt der Bildschirm den Tag.

![Geräte mit dem Abschnitt Anzeigen im Pausenraum nach dem Koppeln](images/app/geraete-anzeige-koppeln.png)

## Widerrufen {#widerrufen}

Bei der Anzeige in der Liste auf **Widerrufen** klicken und die Rückfrage bestätigen. Die Anzeige meldet sich ab und zeigt wieder einen Code. So geht es auch, wenn ein Bildschirm ausgetauscht wird oder verloren geht.

## Gut zu wissen {#hinweise}

- Der Code gilt 10 Minuten.
- Die Anzeige liest nur. Termine anlegen, verschieben oder absagen kann sie nicht, und Gesundheitsdaten zeigt sie nie.
