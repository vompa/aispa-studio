# Anmelden

Wie man sich in der Windows-App anmeldet, hängt vom Betrieb ab: mit Server über einen Code von der Seite „Anmelden“ im Browser, im Einzelplatz mit Benutzername und Passwort.

## Mit Server: Code aus dem Browser {#code}

1. Im Browser die Seite „Anmelden“ des Spas öffnen und mit dem Passkey anmelden ([Seite „Anmelden“ im Browser](hilfe:anmelden-web)).
2. **Code für die Windows-App** wählen. Die Seite zeigt einen Code mit der Zeit, bis wann er gilt.
3. In der Windows-App den Code ins Feld „ABCD-EFGH“ tippen.
4. Auf **Anmelden** klicken.

![Anmeldung mit Code](images/app/anmeldung.png)

- Der Code gilt nur kurz und nur einmal; die Seite nennt die Uhrzeit.
- „Die App bleibt danach auf diesem PC angemeldet.“ Beim nächsten Start ist keine Anmeldung nötig, bis man sich abmeldet.

## Einzelplatz: Benutzername und Passwort {#passwort}

1. „Benutzername“ und „Passwort“ eintragen. Benutzername und Startpasswort vergibt die Leitung unter **Verwaltung** › **Team**, Reiter **Zugang und Rolle**.
2. Auf **Anmelden** klicken (oder Enter).
3. Beim ersten Mal mit Startpasswort erscheint „Eigenes Passwort wählen“: zweimal ein neues Passwort mit mindestens 8 Zeichen eintragen und **Passwort ändern und anmelden** klicken.

- Nach fünf falschen Passwörtern ist das Konto fünf Minuten gesperrt.
- Passwort vergessen: [Passwort vergessen](hilfe:anmeldung-passwort-vergessen).

## Gut zu wissen {#hinweise}

- „Für dieses Konto ist kein Zugang eingerichtet oder er wurde gesperrt.“: die Leitung prüft den Zugang unter **Verwaltung** › **Team**, siehe [Zugänge](hilfe:zugaenge#zugang-bearbeiten).
- Was man nach der Anmeldung sieht, hängt von der Rolle ab: [Rollen](hilfe:zugaenge#rollen).
- Am Empfangsgerät geht es schneller mit Name und PIN: [Schnellwechsel](hilfe:anmeldung-schnellwechsel).
