# Gutschein einlösen

Ein Gutschein ist an der Kassa eine Zahlungsart: Code und Betrag im Feld „Gutschein“ eintragen, den Rest mit einer anderen Zahlungsart begleichen.

## Wertgutschein {#wertgutschein}

1. Termin, Artikel oder Eintritt auf die Rechnung setzen, z. B. [Termin kassieren](hilfe:kassa-termin-kassieren).
2. Rechts unter „Bezahlen“ bei **Gutschein-Code** den Code vom Gutschein eintippen, z. B. `K7M3-Q9XA-B2CD` (drei Blöcke zu vier Zeichen), und das Feld verlassen. Unter dem Feld stehen Restwert und Gültigkeit. Ist das Feld **Gutschein** noch leer, trägt die Kassa den Restwert ein, höchstens den offenen Betrag.
3. Beim Feld **Gutschein** den Betrag prüfen. Soll weniger vom Gutschein abgehen, den Betrag ändern.
4. Einen noch offenen Betrag mit einer anderen Zahlungsart bezahlen, z. B. bei **Bar gegeben** auf **Rest** klicken.
5. Auf **Bezahlen und Beleg erstellen** klicken. Der Beleg zeigt die Zahlung als „Gutschein K7M3-…“.

## Behandlungsgutschein {#behandlung}

Ein Gutschein für eine bestimmte Behandlung gilt nur, wenn genau diese Behandlung als Termin auf der Rechnung steht.

1. Den Termin mit dieser Behandlung auf die Rechnung setzen.
2. Beim Feld **Gutschein** den Preis der Behandlung eintragen und bei **Gutschein-Code** den Code eintippen.
3. Auf **Bezahlen und Beleg erstellen** klicken. Der Beleg zeigt eine eigene Zeile „Einzweckgutschein … eingelöst“, die den Termin mindert.

## Fehlermeldungen {#fehler}

- „Diesen Gutschein-Code gibt es nicht.“: den Code prüfen.
- „… · nicht mehr gültig“ unter dem Feld oder „Gutschein … ist nicht mehr gültig (Restwert …)“ beim Bezahlen: der Gutschein ist aufgebraucht oder storniert.
- „Gutschein … ist am … abgelaufen.“: das Datum „Einzulösen bis“ auf Beleg und Gutschein ist vorbei. Woher das Datum kommt: [Ablaufdatum](hilfe:kassa-gutschein-verkaufen#ablaufdatum).
- „Gutschein …: höchstens … einlösbar.“: der eingetragene Betrag ist höher als der Restwert. Den Restwert eintragen und den Rest anders bezahlen.
- „Gutschein … gilt nur für eine bestimmte Behandlung, die nicht auf diesem Beleg steht.“

## Gut zu wissen {#hinweise}

- Ein Wertgutschein lässt sich in mehreren Besuchen aufbrauchen; der Rest bleibt auf dem Code.
- Bezahlen geht erst, wenn zu jedem Gutschein-Betrag ein Code eingetragen ist.
- Wird der Beleg später storniert, bekommt der Gutschein seinen Wert zurück.
- Mit Gutschein bezahlt, gibt es keinen Barzahlungsrabatt.
- Pakete (z. B. 10er-Block) zieht die Kassa mit einem Klick ab: [Paket verkaufen und abziehen](hilfe:kassa-paket#abziehen).
- Siehe auch [Bezahlen](hilfe:kassa-bezahlen) und [Gutschein verkaufen](hilfe:kassa-gutschein-verkaufen).
