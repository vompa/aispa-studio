# Paket verkaufen und abziehen

Ein Paket ist ein Gutschein für mehrere gleiche Behandlungen, z. B. ein 10er-Block Massage. Es gehört einem Gast, wird beim Kauf versteuert und bei jedem Termin um eine Behandlung weniger.

## Paket verkaufen {#verkaufen}

1. Einen Termin oder Eintritt des Gastes auf die Rechnung setzen, damit die Rechnung einen Gast hat, z. B. [Termin kassieren](hilfe:kassa-termin-kassieren).
2. Im Panel „Artikel und Gutscheine“ neben der Rechnung (aufklappen, falls nur die schmale Leiste zu sehen ist) unter **Gutschein verkaufen** bei **Behandlung** die Behandlung wählen.
3. Darunter die Anzahl eintragen (2 bis 50, vorbelegt mit 10), wenn gewünscht einen **Paketpreis** (leer heißt Einzelpreis mal Anzahl) und ein Ablaufdatum unter **gültig bis** (leer heißt unbefristet).
4. Auf **Paket verkaufen** klicken. Auf der Rechnung steht „Paket 10× …“.
5. Wie gewohnt bezahlen. Der Code des Pakets steht auf dem Beleg.

## Termin vom Paket abziehen {#abziehen}

1. Den Termin des Gastes auf die Rechnung setzen.
2. Hat der Gast ein Paket für diese Behandlung, steht rechts unter **Bezahlen** z. B. „Paket Klassische Massage: 7 von 10 offen“.
3. Auf **1 Termin abziehen** klicken. Die Kassa trägt das Paket als Gutschein-Zahlung über den Preis des Termins ein.
4. Auf **Bezahlen und Beleg erstellen** klicken. Der Beleg zeigt „Paket … eingelöst (4/10)“, zu zahlen bleibt für diesen Termin nichts.

![Kassa mit Paket zum Abziehen](images/app/kassa-paket.png)

Stehen mehrere Termine mit derselben Behandlung auf der Rechnung, zieht die Kassa je Termin eine Behandlung ab, solange das Paket reicht.

## Im Kalender {#kalender}

- Die Hover-Karte eines Termins nennt das Paket, z. B. „Paket Massage: 7 von 10 offen“.
- Ein orangefarbenes **P** erscheint erst, wenn es die letzte Behandlung des Pakets ist oder das Paket innerhalb von 30 Tagen abläuft. Dann lohnt es sich, ein neues Paket anzubieten.

## Gut zu wissen {#hinweise}

- Steuerlich ist ein Paket ein Einzweckgutschein: Die Umsatzsteuer fällt beim Kauf an, das Abziehen ist kein neuer Umsatz.
- Wird der Beleg mit dem Abzug storniert, bekommt das Paket die Behandlungen zurück. Den Kauf eines Pakets kann man nur stornieren, solange noch nichts davon abgezogen ist.
- Ein Ablaufdatum ist freiwillig. Eine kurze Befristung von Gutscheinen ist in Österreich rechtlich heikel; im Zweifel unbefristet lassen.
